# how to setup npc crop exchange

q## step-by-step

1. Select account.
2. Open **Villages** tab and select a village.
3. Open **Settings** sub-tab.
4. In **NPC Crop exchange settings**:
   - Enable **Enable NPC Crop exchange**.
   - Set **Granary %**.
   - Set **Ratio** values.
   - Optional: enable **Despite warehouse overflow**.
5. Click **Save**.

## tips

- Start with simple ratio values, then tune based on your village needs.
- Use one village first, confirm behavior, then copy to others.
