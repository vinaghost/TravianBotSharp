# how to edit account or proxy information

## step-by-step

1. Select an account from the left account list.
2. Open the **Edit account** tab.
3. Update main fields if needed (server URL, nickname/username).
4. To change access or proxy data:
   - Select a row in the access table.
   - Edit fields.
   - Click **Edit access**.
5. To add a new access row, fill fields and click **Add access**.
6. To remove an access row, select it and click **Delete access**.
7. Click **Edit account** to save everything.

## tips

- Save changes with **Edit account** after updating access rows.
- If validation fails, check required fields first (username/password or proxy pair values).
