# how to run this bot for the first time

## step-by-step

1. Go to the folder where you extracted TBS.
2. Double-click **TravianBotSharp.exe**.
3. Wait for the main window to open.
4. If this is your first time, start by adding an account.

## common issues

- If the app does not start, make sure you are on Windows.
- If you see a Chrome version warning, update Chrome and start TBS again.
