# how to setup auto train troop

## step-by-step

1. Select account.
2. Open **Villages** tab and select a village.
3. Open **Settings** sub-tab.
4. In **Troop training settings**:
   - Enable **Enable train troop**.
   - Set **Next train troop execute after** range.
   - Pick troops for barrack/stable/great barrack/great stable/workshop (as available).
   - Set amount ranges for each selected troop.
   - Optional: enable **Train maximum number if low on resource**.
5. Click **Save**.

## tips

- Keep small amount ranges first to avoid over-training.
- Not all troop options are useful for every village; set only what you need.
