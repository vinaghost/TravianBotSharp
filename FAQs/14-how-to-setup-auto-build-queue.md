# how to setup auto build queue

## step-by-step

1. Select your account.
2. Click **Pause** on the left panel.
3. Open **Villages** tab and select a village.
4. Open **Build** sub-tab.
5. Add jobs with one of these methods:
   - Select a building and use **Upgrade one level** or **Upgrade max level**.
   - Use middle panel to choose building + level, then click build button.
   - Use resource plan + level, then click build button.
6. Check jobs in the job list (right panel).
7. Reorder jobs if needed (Top, Up, Down, Bottom).
8. Click **Pause** again to resume account and start execution.

## tips

- Keep a clear job order for better results.
- Start with small queues and expand after testing.
