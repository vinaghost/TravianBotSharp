# how to import and export account settings

## step-by-step (export)

1. Select the account.
2. Open **Settings** tab.
3. Click **Export**.
4. Choose file name and location.
5. Save the file.

## step-by-step (import)

1. Select the account.
2. Open **Settings** tab.
3. Click **Import**.
4. Select a settings file.
5. Check values and click **Save** if needed.

## tips

- Keep a backup export before big changes.
- Use account settings templates to speed up setup for new accounts.
