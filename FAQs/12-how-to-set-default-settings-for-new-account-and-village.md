# how to set default settings for new account and village

## what each button does

- **Default settings for new account**: default account settings template.
- **Default settings for new village**: default village settings template.
- **Default building list for new village**: default build job template.

## step-by-step

1. On the left panel, click one of the default template buttons.
2. Choose a `.tbs` template file.
3. Confirm the success message.
4. Add a new account or new village later to apply that default template.

## how to clear a default template

1. Click the same default button again.
2. Confirm clearing when asked.

## tip

Set these templates once to save time when creating many accounts and villages.
