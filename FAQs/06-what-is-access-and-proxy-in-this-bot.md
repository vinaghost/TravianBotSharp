# what is access and proxy in this bot

In TBS, an **account** can have one or more **access** entries.

- **Access** = login data used to open the game (username/password, and optional proxy info).
- **Proxy** = a network route for that access. It is optional.

Why this matters:
- You can keep multiple access options for one account.
- TBS can use different proxy settings per access entry.

If you do not use proxies, you can leave proxy fields empty.

**Warning**: It is safer to use 1 access per account and let account active in 8 to 10 hours per day. Online too much can trigger MH notifications or get reported from other players
