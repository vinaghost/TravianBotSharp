# how to import and export building list

## step-by-step (export)

1. Select account and village.
2. Pause account.
3. Open **Villages > Build**.
4. Click **Export**.
5. Save the file.

## step-by-step (import)

1. Select account and village.
2. Pause account.
3. Open **Villages > Build**.
4. Click **Import**.
5. Pick the building list file.
6. Confirm prompts (including optional random location).
7. Review imported jobs in the right-side job list.

## tips

- Export your current list before importing a new one.
- After import, review job order and adjust if needed.
