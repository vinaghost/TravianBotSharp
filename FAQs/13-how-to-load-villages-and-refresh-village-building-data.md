# how to load villages and refresh village building data

## step-by-step

1. Select an account from the left list.
2. Open the **Villages** tab.
3. Pick a village in the village list.
4. Right-click the village list to open menu.
5. Choose one option:
   - **Reload this village's building**
   - **Reload village that missing building**
   - **Reload all village**
6. Wait for tasks to finish and village data to refresh.

## tip

Use “missing building” option when you only want to fix incomplete village data.
