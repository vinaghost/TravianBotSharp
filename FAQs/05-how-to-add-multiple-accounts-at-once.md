# how to add multiple accounts at once

## step-by-step

1. Open TBS.
2. Click **Add accounts** on the left side.
3. In the big input box, paste lines in this format:

   `https://server.url username password [proxy_host] [proxy_port] [proxy_username] [proxy_password]`

4. Use one line per account.
5. Check the preview table below the input box.
6. Click **Add accounts**.

## examples

Without proxy:

`https://ts1.x1.international.travian.com myuser#tag mypass`

`https://ts1.x1.international.travian.com myuser@mail.com mypass`

With proxy:

`https://ts1.x1.international.travian.com myuser#tag mypass 127.0.0.1 8080 proxyUser proxyPass`

`https://ts1.x1.international.travian.com myuser@mail.com mypass 127.0.0.1 8080 proxyUser proxyPass`

## tips

- Keep spaces clean (single spaces between values).
- If a line is invalid, it may not appear in the preview table.
